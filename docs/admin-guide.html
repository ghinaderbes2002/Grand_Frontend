دليل لوحة التحكم

كيف تضيف منتجاتك وتدير متجرك — خطوة بخطوة

للدخول: سجّل دخول بحساب الإدارة، ثم اضغط «لوحة التحكم» بأعلى الموقع. القائمة الجانبية فيها كل الأقسام.

إضافة منتج — بهذا الترتيب

  1. جهّز الأصنافالأصناف ← إضافة — مثل: أحبار، ورق، آلات. للصنف الفرعي اختر «الصنف الأب».
  2. عرّف الصفات (مرة وحدة بس)الصفات ← إضافة — مثل: اللون، المقاس، الوزن. بعدها افتح الصنف واضغط «ربط صفة». فعّل «تُنشئ متغيرات» إذا المنتج بيجي بأكتر من لون أو مقاس.
  3. أضف العلامة التجارية والمستودعالعلامات التجارية (مثل Epson) — والمستودعات (مثل MAIN). المستودع مطلوب لتسجّل الكميات.
  4. أنشئ المنتجالمنتجات ← إضافة ← اختر الصنف ← «متابعة» ← عبّي الاسم والوصف و SKU ووحدة البيع.
  5. ارفع الصورمن صفحة المنتج، قسم «الصور» ← «رفع صورة». أول صورة هي اللي بتظهر بالمتجر.
  6. حطّ السعرقسم «الأسعار» — سعر التجزئة إلزامي، وسعر الجملة اختياري (بيظهر لزبائن الجملة بس).
  7. سجّل الكمية«المخزون» ← «استلام بضاعة» ← اختر المستودع والكمية.
  8. انشر المنتجغيّر الحالة من «مسودة» إلى «منشور» — هلق صار ظاهر بالمتجر.
منتج بأكتر من لون أو مقاس؟ من صفحة المنتج ← «المتغيرات» ← «متغيّر جديد». كل متغيّر إلو SKU وسعر وكمية لحاله.

باقي الأقسام

استيراد المنتجاتلإضافة منتجات كتير دفعة وحدة: ارفع ملف CSV ← «رفع ومعاينة» ← صحّح الأخطاء ← «اعتماد الدفعة».
الكوبوناتكود خصم بنسبة مئوية أو مبلغ ثابت، مع تاريخ بداية ونهاية وحد للاستخدام.
الزبائنعيّن لزبون معيّن قائمة سعر الجملة.
المستخدمونأضف موظفين وحدد دور كل واحد، أو أوقف حساب.
التقاريرالمبيعات، والمنتجات اللي مخزونها قليل، والمنتجات الراكدة.
تسوية جردلتصحيح كمية غلط: «المخزون» ← «تسوية جرد» — رقم موجب بيزيد وسالب بينقص، والسبب إجباري.

نصائح سريعة

• المنتج ما بيظهر بالمتجر إلا إذا كان منشور وإلو سعر تجزئة.
• لإخفاء منتج مؤقتًا: غيّر حالته لـ «مؤرشف» بدل الحذف.
• الـ SKU لازم يكون فريد لكل منتج أو متغيّر.
